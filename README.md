# Учёт посещаемости — GitHub Actions + GitHub Pages

Приложение получает расписание группы ВВГУ через GitHub Actions. Python запускается на стороне GitHub и сохраняет занятия на текущий день в `data/timetable.json`. Браузер загружает готовый JSON, поэтому CORS при обращении к `vvsu.ru` не возникает.

## Настройки проекта

Группа сейчас задана в `update_timetable.py`:
- ID: `21033`
- название: `А/СОПИ-24-1`
- часовой пояс расписания: `Asia/Vladivostok`

Workflow запускается ежедневно в 15:00 UTC (01:00 следующего дня по Владивостоку), а также вручную через **Actions → Update today's timetable → Run workflow**.

## Публикация

1. Создай новый репозиторий GitHub и загрузи в него всё содержимое этой папки, включая скрытую папку `.github`.
2. Открой **Settings → Pages**.
3. В разделе **Build and deployment** выбери **Deploy from a branch**.
4. Выбери ветку `main` и папку `/(root)`, затем сохрани.
5. Открой **Actions**. Если GitHub запросит разрешение на запись workflow, открой **Settings → Actions → General → Workflow permissions**, выбери **Read and write permissions** и сохрани.
6. Запусти workflow вручную: **Actions → Update today's timetable → Run workflow**. Дождись зелёной отметки.
7. Проверь, что в репозитории появился или обновился `data/timetable.json`.
8. Открой адрес GitHub Pages.

## Важно

- GitHub Actions не гарантирует запуск ровно в указанную минуту; запланированный запуск может задержаться.
- Если сайт ВВГУ изменит HTML или начнёт блокировать автоматические запросы, workflow завершится ошибкой. Смотри журнал запуска во вкладке Actions.
- Приложение хранит список студентов и посещаемость только в LocalStorage браузера. Эти данные не отправляются в репозиторий.
- Чтобы вручную обновить расписание, нажми кнопку «Обновить расписание» на сайте: она перечитает опубликованный JSON, но не запускает Python. Для нового запроса к ВВГУ запусти workflow вручную во вкладке Actions.
- Не включай публикацию из другой ветки/папки, если структура репозитория отличается от описанной выше.
