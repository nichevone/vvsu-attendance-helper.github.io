# Учёт посещаемости
Небольшая штука для получения расписания на сегодня и учета посещаемости. Работает в браузере, ничего лишнего не хранит.
Через `update_timetable.py` делается запрос к `https://www.vvsu.ru/timetable/`. Полученные данные о парах на текущий день сохраняются в `data/timetable.json` и отображаются.

## Настройки проекта
Группа сейчас зашита в коде в `update_timetable.py`:
- ID: `21033`
- Имя: `А/СОПИ-24-1`
- Часовой пояс расписания: `Asia/Vladivostok`

Расписание обновляется ежедневно в 01:00 по Владивостоку. Поэтому каждый день пары актуальные.
